# Rowan & Finch — model release review ledger

This repository is the system of record for release decisions made by the data governance group.

File each release outcome as a new issue. The issue title must be `Release review: <model name>` and
the body must begin with the final decision line `Final decision: CLEARED` or `Final decision: HOLD`.
Include the per-dataset licence findings and the benchmark gate result in the body.
